# Breezyfy feature coverage

Reviewed against public Erasio documentation and the Breezyfy source on 29 October 2026. This is an independent implementation using the same general processing category. It is **not an A–Z reproduction or a claim of identical output**. Browser/export verification is recorded separately by the implementation tests.

| Capability observed at Erasio          | Breezyfy implementation / boundary                                                                                                                                                                                                                                              |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Local visible-overlay image correction | Canvas processing, calibrated translucent sparkle maps and reverse alpha blending. Files without a sufficiently confident match are returned unchanged.                                                                                                                         |
| Multiple watermark families            | Compact, classic and modern profiles, plus automatic candidate selection. Coverage does not establish support for every Gemini/Flow revision.                                                                                                                                   |
| PNG/JPG/WebP/BMP image input           | PNG, JPEG, WebP and uncompressed 24/32-bit BMP are supported, with byte/header validation. Animated images and compressed BMP are rejected.                                                                                                                                     |
| Image export                           | PNG, JPEG and WebP; quality for lossy exports. JPEG flattens transparency onto white. Changing format/size applies when correction succeeds; unmatched originals remain unchanged.                                                                                              |
| Adjust/resize                          | Width, height and aspect-ratio control for corrected image exports. There are no image colour-adjustment controls.                                                                                                                                                              |
| MP4 video processing                   | WebCodecs/H.264 re-encoding, per-frame match checks, compatible compressed audio track copying. Unsupported audio is rejected rather than silently discarded.                                                                                                                   |
| Source video dimensions/timing         | Dimensions retained in the website UI; original frame timestamps are passed through. The encoder uses source bitrate metadata or sampled packet statistics, bounded by browser output limits. This independently implemented policy is not claimed to be identical to Erasio's. |
| Batch and ZIP                          | Sequential mixed-media queue, up to 50 files and 512 MB input total. ZIP contains corrected results and is limited to 256 MB. Unmatched originals can be downloaded individually. No directory traversal/import is implemented.                                                 |
| Image/video previews                   | Original/result views, image comparison slider, video playback and expanded preview. The decorative landing-page comparison is labeled illustrative; the interactive demo generates a synthetic overlay.                                                                        |
| Tuning and manual placement            | Profile, strength, scale, detection threshold, feathering and X/Y offsets. Image point placement is per-file. No video point-placement UI, numeric absolute-position fields or held nudge arrows.                                                                               |
| Advanced detection controls            | Erasio's scan stride, refinement radius, minimum/trust NCC separation and preset groups are not reproduced. Breezyfy evaluates a bounded set of candidate positions.                                                                                                            |
| Advanced video controls                | Erasio's opacity modes, diffusion iteration/dilation controls, Pearson warning threshold, overlay luminance and bitrate multiplier UI are not reproduced. Edge feathering is not equivalent to that diffusion pipeline.                                                         |
| Opaque-white variant/fill              | Not implemented. Fully covered original pixels cannot be recovered by inverse blending; this release does not provide local inpainting/fill.                                                                                                                                    |
| Separate Veo/Omni automatic pipeline   | Exact pipeline and proprietary calibration remain unverified and are not implemented as an equivalent dedicated mode. Standard video processing may handle a supported visible sparkle, but this is not complete Veo/Omni parity.                                               |
| Settings/theme/history                 | Removal preferences can be saved locally; theme persists. Media stays in the temporary workspace. No persistent media history or automatic download.                                                                                                                            |
| Account/payment/referral gates         | Intentionally omitted: user requested a free website with no login/payment. No credits, subscriptions, ads or analytics integrations.                                                                                                                                           |
| Extension/Android/Google automation    | Separate Erasio products, outside this website release. Breezyfy does not intercept downloads on Google sites or generate media automatically.                                                                                                                                  |
| Legal/help pages                       | Original terms, privacy, acceptable use, browser storage, guide, technology, FAQ and contact pages. The supplied contact is korisolution@gmail.com. Legal operator identity/jurisdiction and legal review remain launch prerequisites.                                          |

## Additional practical limits

- Images: 50 MB, 40 megapixels and 12,288 pixels on one side; minimum decoded dimensions 16 × 16. UI export fields may set a narrower range.
- Video: 100 MB input, 300 seconds, 4K pixel/edge bounds, 256 MB output and 36,000-frame guard. One video track, up to eight compatible audio tracks. HDR and transparent video are rejected.
- Browser/device codecs, memory and hardware affect support and speed. No claim of perfect removal, lossless video, universal compatibility or preserved invisible provenance is made.
- No selected media is sent to a removal backend by the implementation. Hosting still receives ordinary web requests.

## Evidence and unresolved parity

The [public standard tool](https://erasio.io/tool), [image guide](https://erasio.io/image-watermark-removal-settings-guide), [video guide](https://erasio.io/video-watermark-removal-settings-guide), and [separate Veo/Omni page](https://erasio.io/veo-and-omni-watermark-remover) establish advertised behavior. They do not establish private implementation details. Batch sizes and output-format descriptions conflict across Erasio's pages; `.research/feature-audit.md` records those differences.

Breezyfy's implementation can be reviewed in `src/App.tsx`, `src/utils.ts`, and `src/engine/`. Treat any passing synthetic test as evidence for that tested case, not proof of identical quality across all real-world sources. Exact proprietary source/calibration replication and the separate automatic video model are explicitly outside the established result.
